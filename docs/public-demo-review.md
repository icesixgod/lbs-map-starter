# 公开演示核验

核验日期：2026-10-16。保留 OSM 真实街区、2D/3D、建筑整体点选和手动坐标探索。用途为海外站点技术展示；不宣称已取得中国大陆地图审核或服务资质。

## 已处理

- OSM 原始数据经 OpenFreeMap / OpenMapTiles 或 Overpass 获取，由演示后端整理并返回；页面保留来源署名和 ODbL 入口。代码 MIT 与地图数据库 ODbL 分开说明。
- 原始名称、别名、地址等字段继续删除。新增删除 `surface`、`width`；高度、楼层等尺寸只保留在有建筑标记的要素上，避免夹带道路、桥隧、水体等尺寸属性。覆盖样本、原始 JSON 清洗、旧缓存读取、瓦片属性缓存和 JSON / NDJSON 返回边界。
- Sites 公开版不读取 GPS，不申请浏览器定位权限。GitHub Pages 街区预览同样不启用 GPS。
- 本地版保留可选 GPS；确认位置使用和周边取图用途后才请求权限。停止、进入后台或离开页面会清除定位状态、停止监听并取消自动取图。不会采集速度，不把精确定位写入调试 DOM。
- 新增“隐私与数据”入口及手动坐标提交提示。不开设联系方式、账号、分析追踪或定位历史数据库，不把说明写成已经完成合规认证。
- 页面和接口使用 `no-referrer`；地图接口禁止缓存和搜索索引。这些是减少信息暴露的技术措施，不是访问控制。

## 实际数据流

公开版：浏览器提交当前浏览或手动选择的地图区域 → Sites / Cloudflare 上的 `/api/map` → OpenFreeMap 或 Overpass → 去名后的地图数据 → 浏览器渲染。

公开版的服务实例关闭磁盘缓存；应用没有主动保存访客定位历史。托管/CDN、数据源可能留存访问日志并在境外处理请求，不能据此保证日志不存在、立即删除或位于中国境内。

本地版：精确设备位置留在页面内存；跟随取图使用网格化区域中心。默认本地服务会缓存地图区域，可用 `npm start -- --no-cache` 关闭；退出后可删除 `.cache/`。缓存区域可能反映曾浏览的地理范围，不能当作隐私匿名化证明。
